# Velocity Download Manager V2: user guide

These guides are for people who use Velocity Download Manager V2. How V2 is built and tested is in the [developer documents](../README.md).

V2 is a separate app from the original Velocity Download Manager (V1). You can install and run both at once; nothing one does changes the other ([V1 and V2](v1-and-v2.md)).

| Guide | What it covers |
|---|---|
| [Installing](installing.md) | The Windows installer and the Linux packages, upgrading and removing V2 |
| [Downloads](downloads.md) | Adding downloads, the download list, the details panel, the history, files and folders, logins |
| [Protocols and limits](protocols.md) | What V2 downloads (HTTP, HTTPS, FTP, FTPS, SFTP, Metalink, BitTorrent), and what each can do |
| [Torrents](torrents.md) | Adding torrents and magnet links, choosing files, seeding, trackers |
| [Categories](categories.md) | Sorting downloads by file type into folders |
| [Settings](settings.md) | Every section of the Settings screen, including the proxy |
| [Browser integration](browser.md) | Sending downloads from Chrome, Edge, Brave and Firefox to V2 |
| [Troubleshooting](troubleshooting.md) | Common problems, the diagnostics report, and what error messages mean |
| [V1 and V2](v1-and-v2.md) | Using both side by side, and how V2 differs from V1 |

**V2 is still in development.** The guides describe what this version does. Where something isn't there yet, the guide says so.
