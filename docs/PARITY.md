# Parity map: V1 to V2

Every user-visible behaviour of the original Velocity Download Manager (V1), with where it lives in V1, the V1 tests that prove it, what V2 does with it, and the V2 issue that delivers it (#22). The default is **keep every V1 feature**. Rows that changed meaning without aria2 were decided in #23 ([ADR-0005](decisions/0005-v1-features-without-aria2.md)); any further scope change needs a new PO decision.

- **V1 reference:** `Singlbase-Technologies-Limited/velocity-download-manager` at commit `e9d717a8`. Every link below opens that exact commit.
- **Dispositions:**
  - **Reuse:** the same behaviour, ported in substance.
  - **Reimplement:** the same behaviour, written again for V2's architecture.
  - **Adapt:** the same user outcome, on V2's own engine.
  - **Decided (ADR-0005):** a behaviour whose meaning changed without aria2, with the PO's decision.
- **V1 tests:** where a behaviour has no V1 test, the row says so, and the V2 issue adds one (#15).
- **Final acceptance** of this map is #85 (V1 against V2 parity).
